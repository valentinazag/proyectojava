# Java Product Management System

A product management and inventory simulation system built in Java using Object-Oriented Programming (OOP), custom exceptions, validation handling, and clean code organization principles.


# Project Purpose

This project was created to practice core and intermediate Java concepts while simulating the structure of a real-world backend application.

The main goals of the project are:

- Practice Object-Oriented Programming (OOP)
- Understand encapsulation and abstraction
- Work with custom exceptions
- Separate responsibilities between classes
- Build clean and maintainable code
- Simulate business logic used in inventory systems

# What Does the System Do?

The application allows basic product and inventory management.

Main features include:

- Creating products
- Listing products
- Searching products (by name and by id)
- Updating stock
- Validating user input
- Handling custom exceptions
- Controlling insufficient stock situations
